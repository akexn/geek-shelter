## Файл

`diagnostic_2025_12_03.php` - диагностика за 3 декабря 2025 года

## Использование

### Через браузер

1. Откройте в браузере:
   ```
   https://dev.geek-shelter.com/modules/accupos_sync/accupos_sync/diagnostic_2025_12_03.php

php diagnostic_2025_12_03.php > diagnostic_output.html
```

## Примеры проблем и решений

### Проблема: "Не все параметры подключения настроены"
**Решение:** Проверьте настройки модуля в админ-панели PrestaShop:
```
Модули → AccuPOS Sync → Настройки
```

### Проблема: "Отсутствуют необходимые таблицы"
**Решение:** Проверьте подключение к AccuPOS Cloud и правильность имени базы данных.

### Проблема: "Транзакции в AccuPOS, но не в PrestaShop"
**Решение:** Запустите ручную синхронизацию в админ-панели модуля.

### Проблема: "Расхождения в данных"
**Решение:** Проверьте логи синхронизации и при необходимости пересинхронизируйте данные.

## Безопасность

⚠️ **ВАЖНО:** Диагностический скрипт содержит информацию о конфигурации системы. 
Рекомендуется:
- Защитить доступ к файлу через `.htaccess`
- Удалить файл после диагностики
- Не оставлять JSON файлы с результатами в публичной директории

## Логирование

Все ошибки также логируются в стандартные логи PrestaShop:
```
/var/logs/error.log
```

3. Свяжитесь с разработчиком: info@impserver.ru
